# 9. Evaluation

Before submitting your project, make sure that your application is **fully deployed** and accessible online.

The goal of this task is to understand the evaluation criteria that will be used during project correction.

---

## Submission

- You must deploy your application on **GitHub Pages** and **provide the public URL** through the dedicated field.
- Only deployed projects can be evaluated.

---

## Visual accuracy

- Your deployed application must closely match the provided [live preview](https://fchavonet.github.io/curriculum-holbertonschool-front_end-frameworks/).
- Particular attention will be given to:
    - Layout structure.
    - Spacing and alignment.
    - Typography.
    - Colors.
    - Responsive behavior.
    - Component organization.
    - Overall visual consistency.
- The objective is to **reproduce the provided design** as accurately as possible.

---

## Lighthouse score

- Your application must achieve a minimum **Lighthouse** score of **95** in each of the following categories:

| Category       | Minimum score |
| -------------- | ------------- |
| Performance    | 95            |
| Accessibility  | 95            |
| Best Practices | 95            |
| SEO            | 95            |

_We strongly recommend running Lighthouse locally before submitting your project._

---

## HTML semantics

- The **semantic quality** of the generated HTML will be evaluated using the [W3C Validator](
https://validator.w3.org/#validate_by_uri).
- Your application should:
    - Produce valid HTML.
    - Use semantic elements appropriately.
    - Avoid major validation errors.
- Particular attention should be paid to:
    - `header`.
    - `main`.
    - `section`.
    - `article`.
    - `footer`.
    - heading hierarchy (`h1` → `h6`).
    - image alternative text (`alt`).

---

## Evaluation criteria

- To successfully complete this project, your application must:
    - Be publicly accessible through GitHub Pages.
    - Closely match the provided live preview.
    - Achieve a minimum Lighthouse score of **95** in all categories.
    - Pass HTML validation without major errors.

---

## Deliverable

- Submit the URL of your deployed application in the dedicated field below.

    - Example:

```text
https://your-github-username.github.io/holbertonschool-agentic_ai/front_end-frameworks/react/
```
