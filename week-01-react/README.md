# React

## Description

This project introduces the fundamentals of React through the development of a modern frontend application.

Students will learn how to initialize a React project with Vite, organize a component-based architecture, manage data with props and state, handle user interactions, render dynamic content and progressively build a structured, responsive and maintainable interface.

This project is the first step of the frontend frameworks curriculum. The same application will later be migrated to Vue.js and Svelte in order to compare different frontend approaches.

## Objectives

At the end of this project, I should be able to explain to anyone, **without the help of Google**:

- _What React is._
- _What a frontend framework is._
- _Why component-based architecture is useful._
- _How to initialize a React project with Vite._
- _How a React project is structured._
- _How to create and import React components._
- _How to split an interface into reusable components._
- _How to pass data between components using props._
- _How to manage local state with `useState`._
- _How to handle user events._
- _How to render content conditionally._
- _How to render dynamic lists._
- _How to organize files and folders in a React project._
- _How to build a responsive interface._
- _How to improve accessibility in a frontend application._
- _How to prepare a React project for deployment._

## Requirements

- Use React.
- Use Vite to initialize and run the project.
- Use JavaScript.
- Use Tailwind CSS.
- Use DaisyUI.
- Respect the provided design references.
- Follow a component-based architecture.
- Keep components clear, reusable and maintainable.
- Use meaningful file and component names.
- Keep the application responsive.
- Keep the interface accessible.
- Do not use another frontend framework for this project.
- The project must run locally without errors.
- The final result must match the expected visual structure and user experience.

## Installation & Usage

### Installation

1. Clone this repository:
    - Open your preferred Terminal.
    - Navigate to the directory where you want to clone the repository.
    - Run the following command:

```
git clone https://github.com/fchavonet/curriculum-holbertonschool-front_end-frameworks.git
```

2. Open the cloned repository.

3. Go to the `week-01-react` folder.

4. Read the task instructions [`README.md`](./tasks/README.md).

5. Start the project by following Task [`0 - Project setup`](./tasks/0-project_setup.md).

### Usage

1. Complete each task in order until the end of the project.

2. Once the tasks are completed, the result can be compared with the demonstration project available in the `project` folder or tested online by clicking [here](https://fchavonet.github.io/curriculum-holbertonschool-front_end-frameworks/).
