# Curriculum Holberton School <br> Front end : frameworks

## Description

This repository contains a frontend curriculum dedicated to the discovery, practice and comparison of modern JavaScript frameworks.

The goal of this curriculum is to help students understand how frontend applications are structured, how component-based development works, and how similar concepts can be implemented across different frameworks such as React, Vue.js and Svelte.

Throughout the project, students will progressively build and migrate the same application using multiple frontend technologies. This approach allows them to compare syntax, reactivity models, component architecture, state management and development workflows in a practical and structured way.

### Curriculum Structure

The curriculum is organized into two main weeks:

- Week 1 - React

Students will start by creating the application with React.
<br>
They will learn how to initialize a frontend project, organize components, manage props and state, handle events, render dynamic content and structure a modern frontend interface.

- Week 2 - Vue.js and Svelte

Students will then migrate the same application to Vue.js and Svelte.
<br>
The objective is to preserve the same features and user experience while understanding how each framework approaches components, reactivity, data binding and project organization.

### Learning Objectives

At the end of this curriculum, students should be able to:

- Explain what a frontend framework is.
- Understand the purpose of component-based architecture.
- Create and organize a frontend application with React, Vue.js and Svelte.
- Compare similarities and differences between modern frontend frameworks.
- Manage data, events and UI updates in different frameworks.
- Migrate an existing interface from one framework to another.
- Identify how framework syntax influences development workflow..
- Build a structured, responsive and maintainable frontend project.
