# Agentic AI - Svelte correction

Correction reference for the Svelte version of the Agentic AI landing page.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

The application runs on `http://localhost:3000`.

## Available scripts

```bash
npm run dev
npm run lint
npm run fix
npm run build
npm run preview
```
